# Bank-System
A simple Bank Management System built to manage customer banking operations such as account creation, deposit, withdrawal, balance check, and transaction history. 

##  🚀 Features Functionalities
User Account Management

Create new bank accounts

View account details

Edit customer details

Delete accounts

# Transactions

Deposit money

Withdraw money

Transfer funds between accounts

View transaction history

## Authentication
User login/logout functionality

Admin and customer roles with different permissions


## Dashboard
Admin panel for managing users and viewing overall statistics

User dashboard for personal account activities

## Reports

Daily, weekly, and monthly financial reports (Admin only)

Printable account statements



## 🛠️ Technologies Used
## 👨‍💻 Front-End:
HTML

CSS

JavaScript 

## 🧠 Back-End:
Node.js with Express or Python with Flask/Django or PHP

RESTful API for data handling

MySQL
